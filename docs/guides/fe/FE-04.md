## Sección 1: 🎓 Introducción y Fundamentos Conceptuales

### ¿Dónde estamos?
En **FE-03** construimos un sistema de seguridad robusto con autenticación y protección de rutas. Si un usuario intenta acceder al Dashboard sin permisos, es redirigido. Si tiene permisos, ingresa. Sin embargo, una vez dentro, no hay un "esqueleto" visual: no hay menú superior, ni navegación lateral, ni manejo de estados de carga globales.

### ¿Qué vamos a lograr?
En esta guía crearemos el **Layout (Shell) principal de la aplicación**, es decir, la envoltura visual que persistirá a medida que el usuario navegue entre diferentes páginas protegidas. Este layout incluirá:
1. Un `Header` global superior con el logotipo, nombre del usuario actual y un menú de usuario (Logout).
2. Un componente de navegación principal (`Navbar`) responsivo.
3. El uso avanzado de `loading.tsx` y `error.tsx` de Next.js para mejorar la experiencia de usuario (UX) durante transiciones lentas o errores inesperados.

### Concepto Clave: Layouts Anidados y Server Components
Next.js 14+ con App Router permite anidar layouts de forma extremadamente eficiente. En lugar de re-renderizar todo el menú de navegación cada vez que el usuario cambia de página, un Layout (`layout.tsx`) preserva su estado mientras solo su contenido interno (`children`) cambia. 
Además, construiremos nuestro Header como un **Server Component**, permitiendo leer la cookie de sesión desde el servidor sin añadir carga extra (JavaScript) en el cliente.

## Sección 5: 🛠️ Implementación Paso a Paso

### Paso A — Crear el Dashboard Layout

Este es el archivo principal. Aceptará `children` (el contenido de las subpáginas) y lo envolverá con el menú de navegación. Al ser un Server Component por defecto, aprovecharemos para cargar la información del usuario autenticado aquí mismo y pasarla al Header.

**Archivo a crear:** `frontend/app/(dashboard)/layout.tsx`

```tsx
import { ReactNode } from 'react';
import Link from 'next/link';
import { redirect } from 'next/navigation';
import { createClient } from '@/lib/supabase/server';
import { UserMenu } from './_components/user-menu'; // Lo crearemos en el Paso B
import { MainNav } from './_components/main-nav';   // Lo crearemos en el Paso C

export default async function DashboardLayout({ children }: { children: ReactNode }) {
  // 1. Instanciamos el cliente de servidor
  const supabase = await createClient();

  // 2. Obtenemos el usuario autenticado (protección redundante, el middleware ya hace el filtro duro)
  const { data: { user }, error } = await supabase.auth.getUser();

  if (error || !user) {
    redirect('/login');
  }

  // 3. Obtenemos el nombre del perfil desde la BD pública
  const { data: profile } = await supabase
    .from('user_profiles')
    .select('full_name')
    .eq('id', user.id)
    .single();

  const displayName = profile?.full_name || user.email?.split('@')[0] || 'Usuario';
  const email = user.email || '';

  return (
    <div className="flex min-h-screen flex-col bg-slate-950 text-slate-50">
      {/* HEADER SUPERIOR */}
      <header className="sticky top-0 z-40 w-full border-b border-slate-800 bg-slate-950/80 backdrop-blur supports-[backdrop-filter]:bg-slate-950/60">
        <div className="container mx-auto flex h-16 items-center justify-between px-4">
          
          <div className="flex gap-6 md:gap-10">
            {/* LOGOTIPO */}
            <Link href="/dashboard" className="flex items-center space-x-2">
              <span className="inline-block font-bold text-xl tracking-tight">
                ISTQB <span className="text-emerald-400">Agent</span>
              </span>
            </Link>

            {/* NAVEGACIÓN DESKTOP */}
            <MainNav />
          </div>

          {/* MENÚ DE USUARIO (AVATAR + LOGOUT) */}
          <UserMenu email={email} name={displayName} />
          
        </div>
      </header>

      {/* CONTENIDO PRINCIPAL (AQUÍ SE INYECTA CADA PÁGINA) */}
      <main className="flex-1 container mx-auto px-4 py-8">
        {children}
      </main>
    </div>
  );
}
```

### Paso B — Componente de Menú de Usuario (Client Component)

El botón de Logout necesita interactividad y manejar eventos (como clicks). Por lo tanto, extraemos el Avatar y el menú desplegable en un componente del lado del cliente (`"use client"`).

Crea una carpeta `_components` dentro de `(dashboard)`. El guión bajo (`_`) le dice a Next.js que **no** la trate como una ruta pública.

**Archivo a crear:** `frontend/app/(dashboard)/_components/user-menu.tsx`

```tsx
'use client';

import { useRouter } from 'next/navigation';
import { createClient } from '@/lib/supabase/client';
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from '@/components/ui/dropdown-menu';
import { Avatar, AvatarFallback } from '@/components/ui/avatar';

interface UserMenuProps {
  email: string;
  name: string;
}

export function UserMenu({ email, name }: UserMenuProps) {
  const router = useRouter();
  const supabase = createClient();

  const handleLogout = async () => {
    await supabase.auth.signOut();
    router.push('/login');
    router.refresh();
  };

  // Obtener iniciales para el avatar (Ej: Juan Perez -> JP)
  const initials = name
    .split(' ')
    .map((n) => n[0])
    .join('')
    .toUpperCase()
    .substring(0, 2);

  return (
    <DropdownMenu>
      <DropdownMenuTrigger className="focus:outline-none">
        <Avatar className="h-9 w-9 border border-slate-700 bg-slate-800 transition-opacity hover:opacity-80">
          <AvatarFallback className="bg-slate-800 text-slate-300">{initials}</AvatarFallback>
        </Avatar>
      </DropdownMenuTrigger>
      
      <DropdownMenuContent align="end" className="w-56 bg-slate-900 border-slate-800 text-slate-300">
        <DropdownMenuLabel className="font-normal">
          <div className="flex flex-col space-y-1">
            <p className="text-sm font-medium leading-none text-white">{name}</p>
            <p className="text-xs leading-none text-slate-500">{email}</p>
          </div>
        </DropdownMenuLabel>
        <DropdownMenuSeparator className="bg-slate-800" />
        <DropdownMenuItem 
          onClick={handleLogout}
          className="text-red-400 focus:bg-red-950/50 focus:text-red-300 cursor-pointer"
        >
          Cerrar Sesión
        </DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

### Paso C — Componente de Navegación Principal

Agregaremos los links de la aplicación (Dashboard, Mi Plan, Sesión de Estudio). En desktop se verán como texto en el Header, en móvil quedarán ocultos por el momento (la versión móvil completa con el `Sheet` de shadcn se puede iterar luego si es necesario, pero mantendremos un diseño CSS simple primero).

**Archivo a crear:** `frontend/app/(dashboard)/_components/main-nav.tsx`

```tsx
'use client';

import Link from 'next/link';
import { usePathname } from 'next/navigation';

export function MainNav() {
  const pathname = usePathname();

  const routes = [
    { href: '/dashboard', label: 'Dashboard' },
    { href: '/setup', label: 'Mi Plan' },
    { href: '/session', label: 'Sesión Actual' },
  ];

  return (
    <nav className="hidden md:flex items-center space-x-6 text-sm font-medium">
      {routes.map((route) => (
        <Link
          key={route.href}
          href={route.href}
          className={`transition-colors hover:text-emerald-400 ${
            pathname.startsWith(route.href) ? 'text-emerald-400' : 'text-slate-400'
          }`}
        >
          {route.label}
        </Link>
      ))}
    </nav>
  );
}
```

**Archivo a crear:** `frontend/app/(dashboard)/error.tsx`

```tsx
'use client';

import { useEffect } from 'react';
import { Button } from '@/components/ui/button';

export default function DashboardError({
  error,
  reset,
}: {
  error: Error & { digest?: string };
  reset: () => void;
}) {
  useEffect(() => {
    console.error('Unhandled dashboard error:', error);
  }, [error]);

  return (
    <div className="flex min-h-[50vh] flex-col items-center justify-center gap-6 text-center">
      <div>
        <h2 className="text-2xl font-bold text-red-400 mb-2">¡Ups! Algo salió mal.</h2>
        <p className="text-slate-400 max-w-md">
          Ha ocurrido un error inesperado al cargar esta página de la aplicación.
        </p>
      </div>
      <Button 
        onClick={() => reset()} 
        className="bg-slate-800 text-white hover:bg-slate-700"
      >
        Intentar de nuevo
      </Button>
    </div>
  );
}
```

## Sección 7: 🚨 Troubleshooting — Problemas Comunes

| Problema | Causa Probable | Solución |
|---|---|---|
| **Error `user_profiles does not exist` al renderizar el Layout** | La BD no está actualizada. | Ejecuta `supabase db push`. El layout hace un query `SELECT full_name FROM user_profiles`. |
| **El componente de Dropdown (Avatar) no responde a clics** | Falta la directiva de cliente. | Asegúrate de que `app/(dashboard)/_components/user-menu.tsx` tiene `"use client";` en la primera línea. |
| **Next.js se queja de un componente Server tratando de usar hooks de Client.** | Un componente Server está importando hooks. | Revisa que `main-nav.tsx` (que usa `usePathname`) también tenga `"use client";`. El Layout padre puede ser Server Component e importar Client Components sin problema, pero no al revés. |
